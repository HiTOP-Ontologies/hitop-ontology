Faktorisierungs-Diagramm (D3 Icicle-Layout, Prototyp)

Rendert direkt aus factorizations/<id>/v<n>/<version>_diagram.json, generiert von scripts/generate_factorization_diagram_data.py aus der jeweiligen hierarchy.yaml. Ein Band pro Ebene, Breite proportional zur Blattzahl, eine Farbe je oberstem Zweig (Superspektrum/Spektrum) durchgezogen bis zu den Blattknoten — analog zur farblichen Kodierung der offiziellen HiTOP-Abbildung, aber datengetrieben statt handgezeichnet. Diese Demo bettet die JSON-Daten inline ein (kein fetch()), passend zum empfohlenen Build-Muster (mkdocs-gen-files schreibt die Daten direkt in die generierte Seite).
