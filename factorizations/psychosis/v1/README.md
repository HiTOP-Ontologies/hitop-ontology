# Psychosis Superspectrum — v1 (V10749)

Status: **draft**

## What this is

A factorization is a specific, versioned composition of stable HiTOP base
concepts from the shared core ontology (`ontology/hitop.rdf`), expressed as
a recursive hierarchy tree. This factorization tracks the Psychosis
superspectrum structure from Kotov et al. (2020), World Psychiatry,
doi:10.1002/wps.20730. See
[`docs/factorizations.md`](../../../docs/factorizations.md) for the full
governance model, the `hitop:hasLevel`/`hitop:hasLevelType`/`hitop:hasTier`
vocabulary, and how to add a new version.
